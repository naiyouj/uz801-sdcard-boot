# UZ801 SD 卡分区表（sfdisk 可复现格式）
# 恢复命令: sudo sfdisk /dev/sda < 本文件
#
# ⚠️ 关键: label-id 必须是 0x8306c78f
#    分区的 PARTUUID = MBR 磁盘签名 + 分区号
#    boot.img 的 cmdline 写死了 root=PARTUUID=8306c78f-01
#    签名不对 → 起不来
#    事后补救: sudo sfdisk --disk-id /dev/sda 0x8306c78f
# ============================================================

# ------------------------------------------------------------
# 方案 A: 镜像布局（推荐）6G 系统 + 4G 数据 + 1G swap
#   总占用 11G，任何 >=16G 的卡都能用
#   可烧录镜像用的就是这个布局
# ------------------------------------------------------------
