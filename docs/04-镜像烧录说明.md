# UZ801 SD 卡系统镜像 · 烧录说明

像树莓派一样：烧卡 → 插上 → 开机就能用。

---

## 一、镜像文件

| 文件 | 大小 | 用途 |
|---|---|---|
| `uz801-sdcard-20260906.img.gz` | 271 MB | 压缩包，**BalenaEtcher 可直接烧**，不用解压 |
| `uz801-sdcard-20260906.img` | 12.0 GB | 解压好的裸镜像，Rufus / Win32DiskImager 用这个 |

校验值：

```
uz801-sdcard-20260906.img.gz   MD5  0de8e837d2d11d0ee66ee3e3b856d175
uz801-sdcard-20260906.img      MD5  bc41f4d03e5110cda023e7d85b105d14   (未压缩数据)
```

## 二、镜像内容

```
MBR (label-id 0x8306c78f)
├─ sda1   6 GB   ext4   sdroot   系统 rootfs（约 880MB 实际数据）
├─ sda2   4 GB   ext4   sddata   数据盘，挂 /mnt/data
└─ sda3   1 GB   swap   sdswap   交换分区
```

**镜像只占 11 GB**，16G / 32G / 64G 的卡都能烧。烧到 32G 卡后卡尾会剩约 19G，见第四节扩展方法。

镜像已包含：SD 卡启动所需的 `/etc/fstab`（用 PARTUUID）、网口 LAN + WiFi WAN(iKuai2G-982e) 的 NetworkManager 配置、USB host 模式补丁、你原先 `ostk` 目录的备份。

## 三、烧录方法

### 方法 A：BalenaEtcher（推荐，最简单）

1. 打开 Etcher → Flash from file → 选 `uz801-sdcard-20260906.img.gz`
   （Etcher 支持 .gz，会边解压边烧，不用手动解压）
2. 选目标 SD 卡
3. Flash! → 等约 8~15 分钟

### 方法 B：Rufus

1. 选 `uz801-sdcard-20260906.img`（Rufus 不认 .gz，必须用解压好的这个）
2. 分区类型保持默认（MBR）
3. 开始

### 方法 C：Win32DiskImager

同 Rufus，选 `.img`，Write。

> ⚠️ 烧录会清空整张卡，注意别选错盘符。

## 四、烧录后

### 1. 开机

烧好 → 插回 hub → 上电。等约 40 秒，`ping 192.168.9.101`，然后：

```
ssh user@192.168.9.101      # 密码 1
```

验证是否真的跑在 SD 卡上：

```
findmnt -no SOURCE /        # 应输出 /dev/sda1
cat /proc/cmdline           # 应含 root=PARTUUID=8306c78f-01
```

### 2. 扩展卡尾剩余空间（32G/64G 卡强烈建议）

镜像只用了 11G，卡尾剩下的空间建个第 4 分区用起来：

```bash
sudo bash /usr/local/bin/sd-expand.sh
```

脚本会：在剩余空间建 `sda4` → 格式化 ext4 → 挂到 `/mnt/data2` → 写进 `/etc/fstab`。
全程有提示，会先打印分区表让你确认。

### 3. 可选：重新生成 SSH host key

镜像里带着同一份 SSH 主机密钥，如果多台设备烧同一个镜像，SSH 会提示密钥冲突。单台设备无所谓，想换掉就：

```bash
sudo rm -f /etc/ssh/ssh_host_*
sudo dpkg-reconfigure openssh-server
```

## 五、重要前提：eMMC 的 boot 分区必须配套

**这个镜像只包含 rootfs，不含 boot。** 启动用的 boot 在 eMMC 的 `mmcblk0p12` 上，它的 cmdline 写死了：

```
root=PARTUUID=8306c78f-01
```

所以：

- ✅ 现在棒子的 boot 分区已经是 SD 卡版（`boot_v2.img`），**烧完新卡直接就能用**
- ❌ 如果哪天把 boot 刷回原版（`boot.img`，root 指向 eMMC），烧录的 SD 卡不会被启动，系统会走 eMMC

万一 boot 被刷回原版，重新刷一次 SD 卡版 boot 即可：

```
fastboot flash boot boot_sdcard_v2.img
```

文件在 `..\一键只刷boot\boot_sdcard_v2.img`（MD5 `dd9cedffdb866aa6f8f3394e60251ebd`）。

## 六、为什么换卡不用改 boot

分区的 PARTUUID 由 **MBR 磁盘签名 + 分区号** 决定。镜像的磁盘签名固定为 `0x8306c78f`，所以不管烧到哪张卡，`sda1` 的 PARTUUID 永远是 `8306c78f-01`，和 boot 里的 cmdline 对得上。

**自己分区的话必须手动写回签名**，否则起不来：

```bash
sfdisk --disk-id /dev/sda 0x8306c78f
```

## 七、故障处理

| 现象 | 原因 | 解决 |
|---|---|---|
| 起不来，卡在 initramfs | SD 卡没插好 / 卡坏了 / boot 不是 SD 卡版 | 先确认 USB role 和 `lsblk` 能否看到 sda |
| 能起来但 root 是 mmcblk0p14 | boot 是原版 | 刷 `boot_sdcard_v2.img` |
| `/mnt/data` 没挂载 | sda2 未格式化 | `mkfs.ext4 -L sddata /dev/sda2 && mount -a` |
| 完全变砖 | — | 拔 hub 连电脑进 fastboot，跑 `..\一键只刷boot\救砖_刷回原版boot.bat` |
